# Material-Texturen für die Illustrationen

Graue, kachelbare Strukturkarten (Hochpass, Mittelwert 50 % Grau), die `tools/texturize.py`
beim Bauen der Bilder über die SVG-Flächen legt. Das Spiel lädt diese Dateien nicht selbst.

Fast alle stammen von **ambientCG** (https://ambientcg.com) und stehen unter
**CC0 1.0 Universal** (Public Domain): frei nutzbar, auch kommerziell, ohne Namensnennung.
Sie wurden auf 512 px verkleinert, in Graustufen umgewandelt und per Hochpass auf die reine Struktur reduziert.
